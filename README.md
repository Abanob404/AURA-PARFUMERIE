# AURA Parfumerie — Perfume Store Preview

نسخة متجر عطور نظيفة بهوية AURA Parfumerie. لا تحتوي الواجهة أو الأصول أو البيانات التجريبية على هوية المتجر التقني السابق.

## وضع العرض المؤقت
- `PERFUME_PREVIEW_MODE = true` داخل `perfume-demo.js`.
- العطور والصور والأسعار الحالية تجريبية لمراجعة الاستايل فقط.
- بيانات التواصل والسوشيال غير مربوطة ببيانات حقيقية إلى أن يتم اعتمادها من صاحب المتجر.

## الربط التشغيلي
منطق السلة والطلبات ولوحة الإدارة وربط نظام نقاط البيع محفوظ، لكن كل النصوص الظاهرة للعميل تحمل هوية متجر العطور فقط.

## حقوق التطوير
حقوق المطور تظهر فقط في الفوتر كما طلب صاحب المشروع.


## الروابط النظيفة
- الرئيسية: `/`
- العطور: `/products`
- تجربة AURA: `/services`
- الإدارة: `/admin`
- لا تحتاج كتابة `.html` في أي رابط، و`cleanUrls` مفعّل على Vercel.

## حساب الإدارة الأولي
- اسم المستخدم: `admin`
- كلمة المرور: `123456`
- يتم إنشاء الحساب كمالك بصلاحيات كاملة إذا لم يكن موجوداً بالفعل في قاعدة البيانات.
- يفضّل تغيير كلمة المرور بعد أول دخول.
